# 中国大学生智能车大赛 · 自由竞速组

用于团队整理比赛代码、硬件设计、学习资料与调参记录的公开协作仓库。非官方资料库，参赛要求以当届赛事官方通知和规则为准。

## 目录导航

| 目录 | 用途 |
| --- | --- |
| [firmware](firmware/README.md) | 主控固件、驱动与控制算法 |
| [hardware](hardware/README.md) | 原理图、PCB、接线说明及物料清单 |
| [docs](docs/README.md) | 规则索引、学习笔记、方案与操作说明 |
| [tuning](tuning/README.md) | 参数配置、测试条件与实验记录 |
| [tools](tools/README.md) | 上位机、数据处理与辅助脚本 |

## 开始使用

- 浏览和编辑：进入对应目录，使用 GitHub 的 Add file 上传或新建文件；已有文件可通过编辑按钮修改并提交。
- 本地协作：克隆后创建工作分支，通过 Pull Request 合并；详见 [贡献指南](CONTRIBUTING.md)。

```sh
git clone https://github.com/hboy23850-commits/smartcar-free-racing.git
cd smartcar-free-racing
git switch -c work/your-topic
```

## 当前状态与构建

当前仅初始化资料与协作结构，尚未包含赛车固件、可编译工程或自动构建流程。确定主控型号、开发板、SDK 和编译工具链后，再在 firmware 中添加真实工程及可复现的构建、下载与测试说明；不提供未经验证的编译命令。

## 上传约定

- 代码与文档分开存放，文件命名应表达用途；实验记录注明日期、硬件版本与代码提交版本。
- 不上传密码、令牌、个人隐私、未经授权的队伍代码或受版权限制的资料；外部资料优先登记官方链接、来源与版本。
- 不提交 IDE 缓存及编译产物。大型日志、数据集、视频和发布固件优先使用 Releases 或外部链接；需要版本管理的大文件先评估 Git LFS。
- 上车测试前先进行断电接线检查、抬轮测试与低速验证，确保具备可靠的停车措施。
